# Mongbas 실험 결과

이 폴더는 Mongbas의 주요 실험 결과를 공개용으로 정리한 곳입니다. 숫자만 나열하기보다 어떤 환경에서 무엇을 측정했고, 그 결과로 어디까지 말할 수 있는지를 함께 기록했습니다.

현재 보고서:

- [Linux 성능·보안·원격 QR 평가](./2026-09-linux-evaluation.md)

대용량 원시 로그와 운영 환경 자료는 저장소에 포함하지 않았습니다. 공개 보고서의 수치는 실행 당시 생성한 JSON·TSV·로그와 SHA-256 목록을 다시 대조해 작성했습니다. 인증서, 개인키, 관리자 토큰, 내부 주소와 연구 중인 비공개 문서는 공개 대상에서 제외했습니다.

## 읽을 때 주의할 점

Mongbas는 연구용 프로토타입입니다. 여기서 말하는 통과는 명시된 환경과 시험 항목에서 기대 결과가 나왔다는 뜻입니다. 전자투표의 모든 보안 속성이 증명됐거나 실제 공직선거에 바로 사용할 수 있다는 뜻은 아닙니다.

특히 다음 표현은 사용하지 않습니다.

- 7개 보안 속성 전체가 검증됐다는 주장
- 단일 Linux 호스트의 여러 컨테이너를 독립 기관으로 간주하는 주장
- API 응답 형태가 같다는 이유만으로 완전한 강압 저항성을 얻었다는 주장
- 99,996건이 성공한 실행을 100,000표 성공으로 반올림하는 표현

재현 스크립트는 저장소의 [`deploy/linux`](../../deploy/linux)와 각 패키지의 테스트 명령에 있습니다.
